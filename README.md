# PSE R-STDP

Reward-modulated spike-timing-dependent plasticity on a small spiking network. The Care Invariant is the neuromodulator: the third factor that decides how far back a reward can assign credit.

- **Download:** <https://www.zeravatech.ca/downloads/examples/>, for Ubuntu and Windows, with SHA-256 checksums
- **Licence:** GPL-3.0-or-later; see [LICENSE](LICENSE) and [NOTICE](NOTICE)

The application is in [`pse-rstdp/`](pse-rstdp/).
